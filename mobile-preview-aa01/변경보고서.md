# SOUL SPACE 모바일 최적화 변경 보고

## 작업 기준

- 기준본: `FINAL/20260919_SOULSPACE_FINAL_v03`
- 요청 ID: `R-20260919-019`
- 적용 범위: 모바일 UI·반응형·성능·동선 안정화
- 유지 범위: 데스크톱 구성, 네 감정 체험의 기획, 고객 원본, 현재 공개 링크
- 배포 상태: 사용자 모바일 확인 전 공개 링크 미반영

## 변경 전 문제

- 모바일에서 전면 파도 이미지와 복수의 블러·혼합·이동 레이어가 동시에 다시 그려져 배경이 심하게 깜빡였다.
- 첫 화면의 감정 진입 버튼과 상단 메뉴가 화면 크기·안전 영역에 따라 어색하게 배치됐다.
- 360px 화면에서 `SOUL SPACE` 제목이 오른쪽으로 잘렸다.
- 카드·설명·체험 화면의 헤더 기준선과 닫기/메뉴 동선이 서로 달랐다.
- 일부 체험은 모바일 화면 높이와 고해상도 캔버스 처리 때문에 불필요한 렌더링 부하가 있었다.

## 변경 내용과 이유

### 1. 파도 배경 깜빡임 제거

- 모바일에서는 움직이는 파도·안개·혼합 레이어를 정지시키고, 한 장의 파도 이미지와 정적인 그라데이션 안개만 합성했다.
- 첫 화면에 중복으로 겹치던 별도 `ocean-surface` 레이어도 모바일에서 제거했다.
- 파도의 미감은 유지하면서 모바일 GPU가 매 프레임 넓은 화면을 다시 합성하지 않도록 했다.

### 2. 모바일 진입 CTA와 내비게이션 정돈

- 첫 화면 하단에 `감정 살펴보기` 버튼을 고정해 한 손으로 누르기 쉬운 위치에 배치했다.
- SOUL SPACE / ABOUT / MENU / 닫기 버튼을 동일한 44px 터치 높이와 안전 영역 기준선에 맞췄다.
- 카드 설명과 체험 중에도 SOUL SPACE·ABOUT·MENU 동선을 유지해 사용자가 현재 위치에서 빠져나갈 수 있게 했다.

### 3. 모바일 비율과 가독성 보정

- 360–430px 화면에서 `SOUL SPACE`가 한 줄로 완전히 보이도록 유동 글자 크기와 최대 폭을 재설정했다.
- `MEET YOUR SOUL` 설명은 좁은 화면에서 자연스럽게 줄바꿈되도록 폭·행간·한글 줄바꿈을 조정했다.
- 카드 영역은 한 장씩 읽는 가로 스냅 구조를 유지하고, 안내문과 좌우 이동 버튼의 위치를 화면 안에 정리했다.
- ABOUT의 세 섹션은 세로 스크롤 흐름으로 전환해 소개 → 네 감정 → 클로징을 모바일에서 끊김 없이 읽도록 했다.

### 4. 체험 성능과 조작 보정

- 네 체험 화면 높이를 `100svh` 기준으로 맞춰 모바일 주소창 변화로 인한 흔들림을 줄였다.
- BLANK 캔버스는 모바일 DPR을 1.5로 제한해 선명도를 유지하면서 픽셀 처리량을 낮췄다.
- 모바일 안내 문구를 마우스/키보드 표현 대신 손가락 터치 기준으로 바꿨다.
- BURNOUT 하단 동작 버튼은 기기 안전 영역을 반영했다.
- MENU·ABOUT·SOUL SPACE로 이탈할 때 각 iframe을 정지·초기화·언로드하고, 재진입 시 새 상태로 불러오는 기존 초기화 체계를 재점검했다.

### 5. 첫 화면 두 번째 섹션 동선 유지

- 감정의 문은 감정 설명만 미리 보여주며, 클릭해도 곧바로 게임으로 진입하지 않는다.
- 실제 체험 진입은 감정 선택 카드에서만 이루어지게 유지했다.

## 현재 판단

모바일에서 가장 큰 문제였던 파도 배경 깜빡임은 움직이는 대형 합성 레이어를 제거해 구조적으로 해결했다. 배경의 몽환적인 수면 이미지는 남기면서 상단 동선, 카드 읽기, 체험 진입과 이탈을 한 흐름으로 정리했기 때문에 기존보다 작품성과 사용성이 함께 안정된 상태다. 공개본 교체는 사용자 모바일 확인 후 진행한다.
